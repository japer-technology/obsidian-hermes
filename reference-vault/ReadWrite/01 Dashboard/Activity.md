# Activity

> [!NOTE]
> Experience preview only. No entries here are operational records.

The activity view combines human edits, agent work, runtime events, approvals,
costs, outputs, and Git changes into one correlated story.

Each meaningful entry should link actor, runtime, task, run, trace ID, commit,
cost, and resulting notes. Ordinary Markdown and [[Git Memory]] preserve the
durable record; live filters and streaming events are an optional richer view.
