# Support

Obsidian Hermes is not yet installable. Support currently covers the design
documents and contribution process.

- Read the [project README](README.md) and
  [documentation index](docs/README.md).
- Use the
  [question template](https://github.com/japer-technology/obsidian-hermes/issues/new?template=question.yml)
  for clarification about this project.
- Use the
  [documentation template](https://github.com/japer-technology/obsidian-hermes/issues/new?template=documentation.yml)
  for unclear, conflicting, or incorrect documentation.
- Use the
  [design proposal template](https://github.com/japer-technology/obsidian-hermes/issues/new?template=design-proposal.yml)
  for new capabilities or architecture changes.
- Report vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md).

For support with Obsidian or Hermes Agent themselves, use the official support
channels for those projects.
